# AR-0091: Mandatory autonomous decision routing trace

1. Add a cross-project executable trace for an autonomous worker encountering
   an important or ambiguous decision.
2. Require Guidance to emit the trigger, Coordinator to materialize one
   revision-bound batch, and UI to return typed events for every point.
3. Verify that direct agent-interface questions are rejected and that
   independent work is batched before the single user handoff.

Acceptance evidence:

- An important decision always routes through the AR--UI bridge.
- Multiple independent AR points produce one UI session and one persisted
  response batch.
- Bypass, stale, partial, and cross-AR traces fail closed.
