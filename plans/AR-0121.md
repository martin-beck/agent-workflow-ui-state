# AR-0121: Android SSH tunnel lifecycle

Implement the Android SSH client/tunnel lifecycle using the Keystore-backed
identity from AR-0120. The rendezvous SSH host, user, port, and forwarding
policy must be configurable; prefer a reverse tunnel through that reachable
relay or SSH server, restrict forwarding, and preserve the existing
revision-bound decision event contract. Handle process restart, network
changes, sleep, and credential revocation.

Acceptance requires emulator tests with a disposable OpenSSH server and
failure fixtures for dropped connections, stale sessions, and port misuse.
