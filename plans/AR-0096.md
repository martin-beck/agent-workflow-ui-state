# AR-0096: Compatibility release and operator qualification

1. Integrate AR-0090 through AR-0095 into the umbrella and child CI gates.
2. Publish synchronized releases only after exact-head checks, cross-project
   contract checks, and the remote qualification report are green.
3. Update operator documentation with the truthful supported matrix and clear
   unqualified/unsupported boundaries.

Acceptance evidence:

- The umbrella pins immutable commits and release tags for every participating
  project and verifies them in CI.
- The release notes link the compatibility report and scenario evidence.
- No release claims native platform or remote behavior without a passing
  qualification row.
