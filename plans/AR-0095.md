# AR-0095: Scenario artifact provenance and freshness

1. Make scenario generation record the source release, input digest, renderer
   version, and generation command in a public-safe manifest.
2. Check recordings as well as screenshots, Markdown, and GUI artifacts for
   stale or missing outputs in CI.
3. Ensure regenerated artifacts are deterministic while preserving human-paced
   asciinema playback and GUI screenshot coverage.

Acceptance evidence:

- A changed scenario input or renderer fails freshness validation until all
  affected artifacts are regenerated.
- Every committed artifact has a matching manifest entry and current release.
