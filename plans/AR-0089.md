# AR-0089: UI compatibility release and umbrella synchronization

The release consumed by autonomous workers must contain the merged dashboard,
hierarchy, directive, pause/resume, rollback/conflict, and scenario-document
work. The umbrella manifest must pin both the immutable tag and exact commit.

Acceptance:

- Product metadata, documentation, and release tag identify the same version
  and exact main commit.
- Full local and hosted product gates pass from the release commit.
- The umbrella update is reviewed and merged, pins the exact UI tag/commit,
  and keeps bridge compatibility metadata synchronized.
- State records contain exact post-merge and publication evidence, with no
  private paths, host identifiers, or credentials.
