# AR-0118: SSH endpoint and connection-name enumeration

Implement deterministic enumeration from the configured SSH alias. Include
`ssh -G` output, DNS and address-family candidates, canonical names, ports,
and host-key fingerprints. Preserve the alias as provenance but never assume
it is usable from the phone. Redact usernames, paths, credentials, and agent
environment details from public artifacts.

Acceptance requires unit fixtures for split DNS, aliases, IPv4-only,
IPv6-only, dual-stack, loopback, link-local, and unresolved names.
