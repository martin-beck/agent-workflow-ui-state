# AR-0083: PowerShell inline-bootstrap compatibility

The supported Windows setup path must not depend on `$PSScriptRoot` being
populated. The installer shall work when downloaded to a temporary file and
when evaluated from an inline `irm`/`ScriptBlock::Create` command.

Acceptance:

- A Windows-capable test harness reproduces the exact inline invocation shape.
- The installer derives its own release-relative resources without an empty
  path and never writes outside the per-user installation root.
- The documented short command succeeds on a clean user profile with Python
  available, and failure messages identify missing prerequisites.
- Tests cover install, repair, version, uninstall, and a failed download/hash
  validation without weakening the immutable release pin.
- Documentation and the short command are regenerated from the tested path.
