# AR-0104: Large-batch performance and release hardening

1. Benchmark rendering, scrolling, filtering, highlighting, and journal writes
   for large decision batches and long Markdown documents.
2. Add bounded-memory/latency budgets and regression checks for GUI, TUI, and
   remote handoff operations.
3. Integrate the UX, control, navigation, audit, and resilience evidence into
   a compatibility release with upgrade/rollback notes.

Acceptance evidence:

- Defined batch/document sizes meet published latency and memory budgets.
- Performance regressions fail CI without weakening correctness gates.
- A release report links UX, accessibility, resilience, and control evidence.
