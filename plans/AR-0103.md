# AR-0103: Fault-injection and resilience qualification

1. Add deterministic fault injection at fetch, render, input, save, upload,
   rename, acknowledgement, and resume boundaries.
2. Run crash/restart, duplicate-event, stale-revision, network flap, disk-full,
   and GUI/TUI termination scenarios in CI.
3. Publish a matrix showing recovery, user-visible status, cleanup, and final
   Coordinator disposition for each fault.

Acceptance evidence:

- No injected failure fabricates acceptance or silently loses an acknowledged
  event.
- Every failure terminates with an actionable user state and bounded cleanup.
- The matrix is run for Linux and Windows-compatible transport paths.
