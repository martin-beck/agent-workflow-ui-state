# AR-0072: Compact remote decision handoff

Shorten the user-facing self-bootstrap command for remote human decision
sessions. Provide compact Windows PowerShell and POSIX forms that fetch the
trusted launcher into a short-lived local directory, pass positional
arguments, derive the conventional event-journal path, preserve explicit
nonstandard event paths, and clean up after GUI-first/TUI-fallback execution.

Acceptance:

- Windows and POSIX handoff generators emit compact, copyable commands;
- fetched launchers accept positional host/session/event/backend arguments;
- the event path is omitted when it follows `<session>.events.jsonl`;
- GUI remains the default and TUI remains selectable/fallback-compatible;
- temporary files/directories are removed on success and failure;
- hostile-input validation and existing SSH-config alias behavior remain;
- focused unit, shell-syntax, probe, and hosted checks pass;
- the merged UI release and umbrella compatibility pin are recorded.
