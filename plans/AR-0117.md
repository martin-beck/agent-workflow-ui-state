# AR-0117: Local Android runner and controlled self-hosted qualification

Provide reproducible local tooling for Android unit, lint, APK, and emulator
qualification. The runner must install or validate a pinned JDK/SDK/API-34
toolchain, bound boot and test time, collect evidence, and never execute
untrusted pull-request code on a private machine. A manual-only GitHub Actions
workflow may target explicitly labelled self-hosted runners.

Acceptance: native bootstrap/doctor/e2e and containerized build paths are
documented and tested; the public workflow remains safe for pull requests;
the implementation is merged through a reviewed PR with exact-head evidence.
