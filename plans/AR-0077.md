# AR-0077: POSIX awui installer and bootstrap parity

Add a no-admin Linux/POSIX one-time installer matching the Windows launcher
workflow. It must install a per-user `awui` command, persist only non-secret
SSH/state routing configuration, validate the pinned release before use, and
support repair, version, and uninstall actions. The installed launcher must
resolve the short batch token and use the existing GUI-first/TUI-fallback
runtime path.

Acceptance:

- `curl` and `wget` installation forms are documented and tested with a local
  fixture server; direct pipe execution remains optional and clearly bounded;
- install, repair, version, uninstall, PATH/profile handling, and idempotency
  work without administrator privileges;
- launcher/config/runtime files are user-private and contain no credentials;
- release and launcher hashes are validated before installation/use;
- Linux architecture, distribution, runtime, display, GUI fallback, SSH
  alias, token resolution, event persistence, and cleanup are tested;
- hostile paths/hosts, failed downloads, interrupted sessions, and malformed
  registries fail closed;
- the UI release and umbrella compatibility pin are updated after all gates.
