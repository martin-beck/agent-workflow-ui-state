# AR-0114: Android CI runner matrix

Provide reproducible CI capacity for Linux x64 Android builds, emulator tests,
and an arm64-compatible build lane. Cache Gradle safely, pin Java/SDK/platform
versions, upload unsigned APKs and test reports, and fail closed on missing
artifacts.

Acceptance: pull requests run unit, lint, APK, and emulator jobs; main runs the
same matrix plus retention-controlled artifacts.
