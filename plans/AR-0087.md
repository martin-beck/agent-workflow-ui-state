# AR-0087: Release and bootstrap freshness gate

Release evidence must describe the artifact users actually fetch. Local
worktree success is insufficient when the published tag, installer hash, and
umbrella compatibility pin differ.

Acceptance:

- CI fetches the immutable release tag and runs installer, token, batch, and
  documentation checks from that exact source.
- Installer hash, release URL, package version, and umbrella manifest pin are
  cross-checked automatically.
- The gate reports local-head versus published-head differences explicitly and
  blocks release claims when they are not reconciled.
- A release note records hosted CI, real-environment qualification, known
  platform limitations, and the exact supported bootstrap commands.
