# AR-0099: Discoverable keyboard, accessibility, and focus system

1. Define one cross-renderer action map with visible key hints, command
   descriptions, focus order, and conflict-free editing mode.
2. Add a command palette/help overlay, accessible names and announcements,
   high-contrast/focus styling, and keyboard-only completion for GUI and TUI.
3. Validate the map on narrow terminals, PowerShell, Linux terminals, and
   Qt off-screen accessibility tests.

Acceptance evidence:

- Every available action is discoverable and has one consistent shortcut.
- Proposal editing never dispatches decision commands for typed characters.
- Keyboard-only and accessibility smoke traces complete a full batch.
