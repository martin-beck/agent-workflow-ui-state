# AR-0101: Precise synchronized document navigation

1. Replace first-match highlighting with authoritative anchor/range metadata
   that supports repeated phrases and multiple highlights per decision.
2. Synchronize TUI and GUI scrolling, page navigation, document switching,
   zoom/wrap behavior, and selected-decision visibility.
3. Add long-document and repeated-phrase fixtures with visual assertions.

Acceptance evidence:

- Every selected decision scrolls to its own correct Design and Work plan
  range, even when text is repeated.
- Manual page navigation preserves highlight identity and viewport context.
- Narrow/resized windows never lose the active anchor.
