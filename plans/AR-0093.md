# AR-0093: Native Windows UI qualification

1. Split Windows qualification into native x64 and explicitly qualified ARM64
   runners instead of labelling an x64 runner as ARM64 by environment.
2. Exercise the actual PySide6 GUI and prompt-toolkit TUI with keyboard input,
   resize, editing, save+exit, and event-journal verification.
3. Verify installation, launcher selection, and identical bridge output on
   supported Windows shells.

Acceptance evidence:

- Native architecture facts are attested by the runner, not caller input.
- GUI and TUI complete a representative batch on Windows.
- Unsupported native architectures are reported as unqualified, never green.
