# AR-0109: Android APK, device, and release qualification

1. Add reproducible unsigned debug APK builds, emulator/device tests, QR camera
   tests, offline/reconnect tests, and artifact publication.
2. Integrate Android evidence into the compatibility release without signing
   or claiming unsupported external devices.

Acceptance evidence:

- CI builds the APK and runs deterministic emulator tests plus protocol hostile
  tests.
- Release documentation identifies the exact APK source commit, compatibility
  contract, installation, rollback, and unsupported boundaries.
