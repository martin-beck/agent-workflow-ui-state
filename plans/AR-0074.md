# AR-0074: One-time awui launcher installation

Provide a short, one-time installation command for a controlling Windows
machine. Install a small `awui` launcher in the user's PATH and create a local
configuration containing the approved SSH alias, coordinator endpoint/state
root, release channel, and cache policy.

Acceptance:

- installation is explicit, reversible, and requires no administrator rights;
- the launcher works from PowerShell and survives ordinary Python/runtime
  changes by bootstrapping its pinned runtime when needed;
- configuration contains no secrets and honors the user's SSH config;
- uninstall/repair and version inspection are supported;
- installation validates the launcher hash/release and fails closed.
