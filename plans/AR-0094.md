# AR-0094: Real cross-platform remote bootstrap round trip

1. Exercise the short bootstrap from a Windows PowerShell client and POSIX
   client against an ephemeral SSH host using an OpenSSH config alias.
2. Verify runtime archive selection, temporary extraction, GUI-first/TUI
   fallback, path quoting, reconnect/resume, and atomic result return.
3. Add failure cases for missing host, expired token, interrupted UI, and
   rejected/stale response; ensure temporary material is removed.

Acceptance evidence:

- A real remote request is fetched and the complete batch is returned to the
  authoritative event path on both client families.
- Secrets/tokens and private request contents do not enter logs or artifacts.
