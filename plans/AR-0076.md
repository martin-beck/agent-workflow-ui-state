# AR-0076: Short-launcher security, compatibility, and documentation gates

Add end-to-end coverage and documentation for token issuance, one-time
installation, short Windows invocation, remote SSH resolution, GUI/TUI
fallback, batch completion, expiry, replay rejection, and event persistence.

Acceptance:

- Windows and Linux integration tests cover local and remote hosts;
- hostile-input, wrong-project, wrong-revision, expiry, replay, and cleanup
  cases fail closed;
- CI exercises the installed launcher and the long-command fallback;
- user documentation contains the one-time setup and short command workflow;
- the UI release and umbrella compatibility pin are updated only after all
  required gates pass.
