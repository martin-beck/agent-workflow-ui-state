# AR-0120: Consented SSH enrollment and host-key security

Define the enrollment protocol for a phone-generated key. Use explicit
approval or a pre-installed enrollment agent to add a restricted public key;
never silently copy a private key or perform an unbounded authorized-keys
mutation. Bind the enrollment to the project, device, expiry, candidate host
key, and session revision.

Acceptance includes hostile tests for QR replay, wrong host key, expired
enrollment, key substitution, unauthorized command/PTY use, and revocation.
