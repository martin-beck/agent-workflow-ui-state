# AR-0092: Authoritative multi-AR batch and document projection

1. Define the batch envelope for independent decisions from multiple ARs,
   retaining AR, revision, dependency, and decision identities.
2. Generate complete Design and Work plan Markdown from the authoritative
   structure graph before UI invocation.
3. Emit per-document anchors/highlights and verify that every batch point is
   visible, selectable, and persisted in one response.

Acceptance evidence:

- A multi-AR fixture produces one batch containing all eligible points.
- Both documents have distinct, valid anchors for every point.
- Empty, duplicate, stale, and partially generated projections fail closed.

Implementation contract:

- `formal/multi-ar-batch.json` defines the Coordinator-owned envelope and
  requires one authoritative structure-graph digest, task revision, and
  `(ar_id, decision_id)` identity for every point.
- `tools/check_multi_ar_batch.py` validates the complete batch before UI
  invocation. It requires both generated Markdown projections to contain every
  point exactly once with distinct anchors present in the document.
- `clients.tui` and `clients.gui` are projections of the same envelope. Their
  sorted point keys and per-document anchor maps must match the authoritative
  projections; clients may not reconstruct or drop points.
- `formal/multi-ar-batch.pass.json` is the round-trip fixture. Empty, duplicate,
  stale-graph, and partial-projection fixtures demonstrate fail-closed behavior.
