# AR-0075: Tokenized short decision launcher

Implement `awui <token>` and `awui <ssh-host> <token>` using the token contract
and one-time launcher installation. Resolve the complete decision batch,
detect the local platform and GUI capability, prefer the GUI, fall back to the
TUI, and persist validated results to the authoritative remote state.

Acceptance:

- the normal user command is at most 20–30 characters for a short token;
- host override remains available without exposing long paths;
- all decisions in the resolved batch open in one UI session;
- GUI/TUI selection and remote event persistence use the existing bridge;
- temporary runtime/cache cleanup and interrupted-session recovery are safe;
- the current long bootstrap command remains a documented fallback.
