# AR-0102: Audit, privacy, and operator control plane

1. Add an in-session audit view for event sequence, acknowledgement, source
   revision, transport attempts, and final disposition.
2. Provide user-controlled export of a redacted diagnostic bundle and explicit
   dry-run/preview mode without exposing prompts, credentials, or private paths.
3. Add policy controls for retention, redaction, log level, and remote staging,
   with fail-closed validation before export or upload.

Acceptance evidence:

- Every displayed audit item is traceable to a revision-bound event.
- Redaction tests prove private request contents and credentials never appear.
- Dry-run performs no Coordinator mutation or remote publication.
