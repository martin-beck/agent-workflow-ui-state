# AR-0123: SSH discovery and tunnel end-to-end matrix

Build disposable OpenSSH and relay fixtures for the complete pairing flow.
Cover SSH-config aliases, split DNS, private/public candidates, IPv4/IPv6,
Windows and Linux launchers, Android emulator networking, reconnect, revocation,
and all hostile enrollment cases. Add an operator-enabled qualification profile
that resolves the existing SSH-config alias `node26` as a temporary public
reachability test, without embedding credentials or making it a CI dependency.
Keep public-IP/STUN probes optional and bounded so ordinary CI remains
deterministic.
