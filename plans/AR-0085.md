# AR-0085: Real Windows SSH GUI/TUI qualification

Qualify the supported user workflow from Windows PowerShell to an authoritative
Linux host using the existing OpenSSH configuration.

Acceptance:

- Clean Windows x64 and ARM64 runners execute the one-time setup and short
  token command without PATH or `$PSScriptRoot` assumptions.
- With GUI capability available, the Qt GUI opens locally; without it, the
  complete prompt-toolkit TUI is selected and remains fully interactive.
- The SSH alias is resolved only through the user's OpenSSH configuration;
  no hostname or credential is hard-coded in the launcher.
- The complete batch appears in one session, all accepted events are returned
  to the authoritative event path, and token consumption is single-use.
- Captured evidence includes backend, architecture, OS, release, batch count,
  event digest, and cleanup; secrets and private paths are redacted.
