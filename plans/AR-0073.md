# AR-0073: Short decision-batch token contract

Define a revision-bound short token for pending decision batches so a user can
start a remote human-decision session without copying a long host, repository,
and session path. The coordinator remains authoritative and resolves the
token only for the intended project, batch, revision, and event destination.

Acceptance:

- tokens are unique, short, copyable, scoped to a project and revision, and
  expire or become invalid after completion;
- the token resolves to the complete batched session, not one decision;
- resolution rejects unknown, expired, replayed, or wrong-revision tokens;
- no credentials or private paths are embedded in the token;
- the bridge schema and coordinator persistence record the mapping and audit
  events.
