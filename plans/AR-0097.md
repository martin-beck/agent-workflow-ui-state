# AR-0097: Durable save and GUI/TUI persistence parity

1. Make Save, Save + Exit, and safe exit emit the same revision-bound journal
   and Coordinator persistence events in both renderers.
2. Make repeated saves idempotent and preserve every accepted decision,
   proposal edit, clarification, and evidence request.
3. Add crash-safe recovery fixtures proving that an acknowledged save is never
   lost and an unacknowledged save is never fabricated.

Acceptance evidence:

- GUI and TUI produce equivalent event journals for the same batch/actions.
- Save state survives process restart and is visible in the session status.
- Duplicate/reordered/stale save events fail closed.
