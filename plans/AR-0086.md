# AR-0086: Authoritative batch fixture and scenario documentation

The scenario corpus, generated Markdown documents, screenshots, recordings,
and token request must all derive from the same complete AR structure graph.

Acceptance:

- A fixture audit proves every top-level and nested Coordinator request is
  represented exactly once in the rendered decision pane.
- Each point retains AR/request identity, revision, proposal IDs, document
  highlights, and packet digest through UI output.
- Generated terminal and GUI captures show the same batch count and decision
  identities as the JSON fixture.
- CI fails on dropped, duplicated, stale, or digest-mismatched decisions and
  refreshes docs only from authoritative source inputs.
